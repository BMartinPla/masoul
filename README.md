# MASOUL

A 640×360 Hi-Bit dark-medieval action roguelike inspired by *Dead Cells*, featuring multiple playable heroes, procedural biomes, bespoke pixel-art sprites and custom bitmap fonts, relic synergies, and persistent soul meta-progression.

## Controls

- **Move**: `A` / `D` or `←` / `→`
- **Jump / Double Jump / Wall-Jump**: `W` / `Space` / `↑`
- **Drop Through Platform**: `S` (or `S` + `Space`)
- **Attack (3-hit combo)**: `J`
- **Roll / Dodge (with air gravity)**: `Shift`
- **Skills**: `Q` / `E`
- **Soul Overdrive**: `V`
- **Heal Flask**: `R`
- **Interact**: `F`
- **Waystone Warp**: `Tab`
- **Mute Audio**: `M`

## Development

```bash
npm install
npm run dev
npm test
npm run build
```
